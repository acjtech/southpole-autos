SOUTHPOLE AUTOS — GITHUB PAGES READY PACKAGE

FILES
- index.html = the complete website in one file.
- images/ = reserved for your future local website images.

CURRENT IMAGE SETUP
The current website keeps its existing Unsplash image URLs, so it will display immediately after publishing.

WHEN YOU WANT TO CHANGE IMAGES LATER
You have two easy options:
1. Quick method: edit the image URL in index.html and replace it with the new image URL.
2. Recommended method: put your new images inside the images/ folder and change the relevant image src/background-image in index.html to images/your-image.jpg.

GITHUB PAGES
Upload index.html to the root of your GitHub repository, then enable:
Settings → Pages → Deploy from a branch → main → / (root) → Save.

IMPORTANT
Keep index.html in the repository root so GitHub Pages can find it automatically.
